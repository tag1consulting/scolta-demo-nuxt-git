# Changelog

## Unreleased

- Fix `SOURCES.md`: it was copied from the Django/Wagtail demo and never
  reframed. Correct the title, the "port of" intro, the Tools Used list
  (Nuxt 3 / scolta / scolta-nuxt instead of Wagtail / Django / scolta-python /
  scolta-django), and the Scolta-config pointer (`lib/config.ts` +
  `scolta.config.mjs`, not `gitmastery/settings.py`).
- Port the GitMastery theme (from the Django/Drupal demos) to feature parity:
  sticky header with brand + collapsible language switcher, sidebar section nav
  with active-page highlighting, hero + section grid on the home page, themed
  per-type article rendering with the `.doc-meta` badge row, and the full
  theme CSS (Inter + Fira Code, Git-orange accent, GitHub-dark code blocks).
- Move the Scolta search widget into the global header (`.site-header__inner`)
  on every page, matching the Drupal/Django demos, with the results/AI panel
  overlaid as a dropdown. The active content language is derived from the route
  (EN at `/<slug>/`, translations at `/<lang>/<slug>/`) and injected as
  `currentLanguage`, and `auto_language_filter` is enabled, so search results and
  the AI overview lock to that page's language. Internal navigation uses
  full-page anchors so the language lock follows every page load.
- Return HTTP 404 for an unknown doc slug (parity with the Next/Drupal/Django
  demos): the catch-all page surfaces the `/api/doc` 404 as its own response
  status instead of rendering a blank 200.
- Serve a real production build in ddev: the post-start hook runs `npm run build`
  (Nitro node-server output + Pagefind index + runtime assets) and the web daemon
  runs `node .output/server/index.mjs` instead of `nuxt dev`. `NODE_ENV` is no
  longer pinned to `development`.
- Resolve the section list, counts, and page-by-slug lookup from a build-time
  content manifest (`lib/content-manifest.ts`, generated by `gen:content`)
  imported by the Nitro server routes — instead of a request-time
  `process.cwd()/content` filesystem read, which was unreliable once Nitro
  bundles the server. Fixes the home-page count and doc-page 404s.
- Enable Scolta AI out of the box via `ai_provider: "amazee"` — a free LiteLLM
  trial is auto-provisioned on first use (no key). Set `SCOLTA_AI_PROVIDER` +
  `SCOLTA_API_KEY` (gitignored `.ddev/config.local.yaml`) to use a custom
  provider instead.
